# Using NorthStar Lite

Open the NorthStar Lite webpage and choose Work and Personal. If you use Chrome or Edge, **Open Markdown** or **Create Markdown** lets NorthStar save back to that file after you approve it. In other browsers, use **Import Markdown** and later choose **Download copy** to get your updated file.

Type a task in the top bar and press Enter once. NorthStar understands dates such as “tomorrow”, “Oct 15”, and “next Friday”; it also finds tags, projects, delegation, and common spelling slips. The task appears right away in one of four fixed priority groups.

The small status at the top is intentionally literal. “Local changes” means your task is safe in this browser but has not been written to Markdown. Choose **Save to Markdown** when ready. If your file changed in another app, NorthStar stops and shows both choices; download the local copy or reload the external file before choosing an explicit overwrite.

After you have opened the site once, it works offline. Keep a backup of important Markdown files outside the browser too. If a browser resets its site data, its local working copy and file connection can be lost, but downloaded or connected Markdown files remain yours.
